# «Форму невозможно сохранить» при добавлении Instagram-тестировщика

Проверено 19 октября 2026 через интерфейс Meta Developers и Instagram. Это описание одного воспроизведённого случая, не универсальная причина ошибки.

## Что наблюдалось

В приложении с Instagram API обе формы — «Роли → Добавить людей» и «Instagram API setup → Добавить аккаунт» — возвращали общую ошибку сохранения. Запрос назначения роли доходил до сервера и возвращал `payload.success: false` без пояснения.

В браузерной диагностике обнаружен отдельный сбой **поиска пользователя**: запрос `/roles/instagram/typeahead/user/` завершался с `ERR_SOCKET_NOT_CONNECTED`. В поле можно было зафиксировать введённый текст, хотя поиск ещё не вернул настоящий профиль.

## Что помогло

1. Перезагрузить страницу Meta и заново открыть добавление Instagram-аккаунта.
2. Выбрать роль «Тестировщик Instagram», ввести точное имя без `@`.
3. Дождаться результата поиска с профилем/аватаром. Выбрать этот результат, а не отправлять свободно введённый текст нажатием Enter.
4. Если появились два одинаковых элемента, удалить элемент без аватара и оставить найденный профиль.
5. Нажать «Добавить». В Instagram открыть «Разрешения сайтов → Приложения и сайты → Приглашения для тестировщиков» и принять приглашение своего приложения.
6. Проверить обе стороны: у приглашения Instagram появилась кнопка «Удалить», а в Meta в списке ролей появился нужный аккаунт с ролью «Тестировщик Instagram».

После выбора найденного профиля приглашение в этом случае сохранилось и было принято. Нет доказательств, что ошибка требовала бизнес-верификации, публикации приложения, дополнительных прав на Direct или смены страны.

Роль тестировщика ещё не является подключением к Postiz и не подтверждает публикацию видео. Следом понадобятся настройка входа, адрес возврата будущей установки, согласованные права и реальный тест публикации.

При повторной диагностике не выгружать HAR, cookies, заголовки авторизации и секрет приложения в репозиторий или чат. Для этой ошибки хватило статуса запроса поиска и обезличенного результата сохранения роли.
