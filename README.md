# Личный контент-завод

Готовые вертикальные ролики → подписи → очередь → Instagram Reels, TikTok и YouTube Shorts.

Монтаж остаётся в существующем скилле. Здесь проектируется хранение готовых материалов, планирование и контроль публикаций.

## Что уже есть

- [Исследование Фазы, GitHub-аналогов и ограничений соцсетей](docs/research-2026-10-18.md).
- [Предложение по первой версии и условия её готовности](docs/first-version.md).
- [Кликабельный макет](prototype/index.html): выбор ролика, подписи по площадкам, перестановка очереди, предварительное распределение по времени. Работает без библиотек и подключений.

**Это исследование и макет, а не работающий сервис автопубликации.** В макете нет подключения аккаунтов, отправки файлов, фоновых задач и постоянного хранения. Выбранные MP4 остаются в браузере до закрытия страницы.

Открыть `prototype/index.html` можно прямо в браузере. Для локального просмотра через HTTP:

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory prototype
```

Затем открыть `http://127.0.0.1:8765`.

Полные автоматические субтитры изученного урока сохранены только локально в `research/private/`. Эта папка исключена из Git. В репозитории — собственные выводы и краткие указатели по времени, без токенов авторизации и полной расшифровки.

Исходный файл `АВО_опросник_сборщик.html` сохранён без изменений: это ранее существовавший опросник, отдельный от контент-завода.
